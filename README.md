# 📊 University Course Feedback Analytics  
## Business Analytics & Business Analysis Project

## 📌 Project Overview

This project is a complete **Business Analysis design solution** for a **University Course Feedback Analytics system**.

The focus is on understanding the problem space, identifying stakeholder needs, and translating them into structured **business requirements, KPIs, and system-level use cases**.

This is a **pure Business Analysis project**, emphasizing requirements engineering and analytical system design rather than implementation.

---

## 🎯 Objectives

- Understand academic feedback challenges and requirements  
- Define clear business goals and system scope  
- Identify stakeholders and user needs  
- Translate business needs into structured system requirements  
- Design measurable KPIs for academic performance evaluation  
- Model system interactions using use cases  

---

## 📄 Business Requirements

### 📌 Business Requirements Document (BRD)

A detailed BRD was developed covering:

- System objectives  
- Project scope and boundaries  
- Business goals and success criteria  
- High-level functional expectations  
- Constraints and assumptions  

---

## 👥 Stakeholder Analysis

Key stakeholders identified:

- 🎓 Students (feedback providers)  
- 👨‍🏫 Lecturers (feedback recipients)  
- 🏛 Department Heads  
- 🧑‍💼 Academic Administrators  

Each stakeholder was analyzed based on:

- Influence level  
- Interest level  
- System interaction role  

---

## 👤 User Personas

Four detailed personas were created representing real-world users:

- Student Persona (feedback submission behavior)  
- Lecturer Persona (performance improvement needs)  
- Admin Persona (system monitoring & reporting)  
- Department Head Persona (strategic decision-making)  

Each persona includes:

- Goals  
- Pain points  
- Behavior patterns  
- System expectations  

---

## 📊 KPI & Metrics Framework

A structured KPI system was designed to measure system effectiveness:

- Course Satisfaction Score  
- Student Sentiment Score  
- Feedback Response Rate  
- Feedback Submission Rate  
- Lecturer Performance Index  
- Course Improvement Rate  
- Feedback Velocity  
- System Engagement Rate  

These KPIs support data-driven academic decision-making.

---

## 🧩 Functional Modeling

### 📌 Use Case Diagram

A complete set of **16 system use cases** was designed covering:

- Feedback submission  
- Feedback analysis  
- Report generation  
- User authentication  
- Course performance tracking  
- Administrative management  
- Notification handling  
- Dashboard analytics
